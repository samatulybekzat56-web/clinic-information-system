# Use Case диаграммасы

## Жүйе туралы

Емхананың ақпараттық жүйесі пациенттерге, дәрігерлерге және әкімшіге қажетті операцияларды орындауға мүмкіндік береді.

## Актерлер

### Пациент
- Жүйеге тіркелу
- Жеке ақпаратын қарау
- Дәрігерді таңдау
- Дәрігерге қабылдауға жазылу
- Қабылдау уақытын қарау

### Дәрігер
- Жүйеге кіру
- Пациенттер туралы ақпаратты қарау
- Қабылдау кестесін қарау
- Пациент туралы медициналық ақпаратты енгізу

### Әкімші
- Пациенттерді басқару
- Дәрігерлерді басқару
- Қабылдау кестесін басқару
- Жүйедегі ақпаратты жаңарту

## Негізгі Use Case-тер

| Актер | Әрекет |
|---|---|

| Дәрігер | Пациент ақпаратын қарау |

| Дәрігер | Медициналық ақпарат енгізу |

| Әкімші | Дәрігерлерді басқару |
