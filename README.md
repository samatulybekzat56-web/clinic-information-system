# Емхананың ақпараттық жүйесі

## Жоба туралы

Бұл жоба емхана жұмысын автоматтандыруға арналған ақпараттық жүйені сипаттайды.

Жүйе пациенттер, дәрігерлер және қабылдау кестесі туралы ақпаратты басқаруға мүмкіндік береді.

## Жобаның мақсаты

Емханадағы ақпаратты сақтау, басқару және қажетті мәліметтерді жылдам табу процесін жеңілдету.

## Негізгі мүмкіндіктері

- пациенттерді тіркеу;
- пациенттер туралы ақпаратты сақтау;
- дәрігерлер туралы ақпаратты басқару;
- дәрігерге қабылдауға жазылу;
- қабылдау кестесін қарау;
- қажетті ақпаратты іздеу.

## Жүйе пайдаланушылары

- Әкімші
- Дәрігер
- Пациент
